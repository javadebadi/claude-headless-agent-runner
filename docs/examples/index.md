# Worked examples

Complete jobs, each with a profile and a request you can adapt. The first two use
only what the first pages taught; the last two return a folder and use a checker
the agent runs on its own work.

- [A summary](summary.md): one text in, one file out.
- [Slides from a book](book-to-slides.md): a folder to read, one file out.
- [Instagram posts from a book](book-to-carousel.md): captions and image prompts that must agree.
- [A course in a given format](course.md): a larger folder, with a script to check it.
